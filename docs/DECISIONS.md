# Журнал решений

Формат: дата · решение · почему · последствия.

---

### 2026-11-03 · Без MVP: делаем полный набор функций сразу

**Почему.** Цель — показать возможности целиком, а не урезанную версию.
**Последствия.** План в `PLAN.md` разбит по модулям, а не по релизам. Модель данных сразу рассчитана на все фичи (чеки, копилки, регулярные), чтобы не было миграций в процессе.

### 2026-11-03 · Локальное хранение в IndexedDB (Dexie), без бэкенда

**Почему.** Ноль инфраструктуры, мгновенный отклик, работа офлайн, приватность (данные не уходят с устройства).
**Последствия.** Нет синхронизации между устройствами — компенсируем экспортом/импортом JSON. Доступ к данным изолирован в `lib/db` и `lib/services`, чтобы позже можно было заменить хранилище на API (например, Prisma + Postgres) без переписывания UI.

### 2026-11-03 · Суммы в тиынах (integer)

**Почему.** Float даёт ошибки округления (`0.1 + 0.2`). Тиыны редко используются, но целое число в минимальных единицах — стандартная практика для денег.
**Последствия.** Конвертация только на границе UI через `lib/money.ts`.

### 2026-11-03 · Даты операций строкой `YYYY-MM-DD`

**Почему.** Операция относится к календарному дню, а не к моменту времени; строка не «уезжает» при смене часового пояса и корректно сортируется лексикографически, что удобно для индексов Dexie.

### 2026-11-03 · Next.js 16 вместо 15

**Почему.** На момент старта актуальная стабильная версия — 16.x; начинать новый проект на предыдущей мажорной версии нет смысла.

### 2026-11-03 · Свои UI-компоненты в стиле shadcn/ui

**Почему.** Реестр shadcn недоступен из окружения разработки, а сам подход shadcn — это и есть «код компонентов в проекте». Пишем компоненты сами поверх Radix UI с теми же соглашениями (CSS-переменные, `cn()`, варианты через `class-variance-authority`).

### 2026-11-03 · Статический экспорт и детальные страницы через query-параметр

**Почему.** `output: 'export'` не умеет динамические маршруты без заранее известных id, а id живут только в IndexedDB пользователя. Поэтому детали — `/goals/view?id=3`, `/products/view?id=5`.
