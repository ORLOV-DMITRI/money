# Документация «Деньги» (учёт расходов в тенге)

Здесь лежит вся проектная документация: что строим, как устроено и где мы сейчас.

| Документ | О чём |
| --- | --- |
| [PLAN.md](./PLAN.md) | План работ с чекбоксами. Единственный источник правды о прогрессе |
| [FEATURES.md](./FEATURES.md) | Функциональная спецификация: что умеет приложение и как себя ведёт |
| [ARCHITECTURE.md](./ARCHITECTURE.md) | Стек, структура папок, модель данных, ключевые потоки |
| [DECISIONS.md](./DECISIONS.md) | Журнал архитектурных решений (почему сделано именно так) |
| [SYNC.md](./SYNC.md) | Синхронизация между устройствами через Supabase |

## Правила ведения

- Закончили пункт → отметили `[x]` в `PLAN.md` в том же коммите, что и код.
- Поменялось поведение фичи → обновили `FEATURES.md`.
- Приняли неочевидное решение → добавили запись в `DECISIONS.md` (дата, контекст, решение, последствия).
- Поменялась модель данных → обновили раздел «Модель данных» в `ARCHITECTURE.md` и версию схемы Dexie.
