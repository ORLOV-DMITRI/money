# Функциональная спецификация

Приложение для личного учёта финансов в казахстанских тенге (₸). Работает в браузере и на телефоне (PWA), все данные хранятся локально на устройстве.

## 1. Деньги и форматирование

- Валюта одна: тенге. Формат отображения: `12 500 ₸`, с тиынами только если они есть: `1 250,50 ₸`.
- Внутри все суммы хранятся целым числом **тиынов** (1 ₸ = 100 тиын), чтобы не было ошибок округления float.
- Ввод суммы принимает `12500`, `12 500`, `12500,5`, `12500.5`, а также простые выражения `1200+850` (удобно для чека).

## 2. Единые деньги

Счетов нет: наличные, карты и прочее — это одни общие деньги. Депозиты и накопления ведутся копилками.

- При первом запуске приложение спрашивает «Сколько у вас сейчас денег?» и записывает это как корректировку «Начальный остаток».
- **Сверить баланс**: вводишь, сколько денег реально есть (без копилок), приложение записывает корректировку на разницу.
- Корректировка (`adjustment`) меняет баланс, но **не попадает** в отчёты о тратах и доходах; её можно открыть и поправить из ленты.

## 3. Баланс

На главной:
- **Всего** — свободные деньги + все копилки.
- **Свободно** = корректировки + приходы − расходы − пополнения копилок + снятия из копилок. Подсвечивается красным, если ушло в минус.
- **В копилках** — сумма всех копилок (включая закрытые: деньги-то никуда не делись).
- Результат месяца: приход − расход за текущий месяц, сравнение с тем же числом дней прошлого месяца.

## 4. Приход

- Сумма, категория дохода (зарплата, фриланс, подарок, кешбэк…), дата, заметка, теги.
- При сохранении прихода срабатывают **автоотчисления в копилки** (см. п. 6): по каждой копилке с `autoPercent > 0` создаётся пополнение на этот процент от суммы. Пользователь видит итог в тосте и может отменить.

## 5. Расходы

### 5.1 Простой расход
Сумма, категория, дата, заметка, теги.

### 5.2 Расход по продуктам (чек)
- Выбираем магазин (или создаём на лету) и дату.
- Добавляем позиции: продукт (автодополнение из справочника или новый), количество, единица (шт / кг / л / г / мл / уп), цена за единицу **или** сумма позиции (второе считается автоматически).
- Каждая позиция имеет категорию (по умолчанию — категория продукта).
- Итог чека считается автоматически. Сохраняется одна транзакция расхода + позиции чека.
- В отчётах по категориям чек раскладывается по категориям позиций.

### 5.3 Быстрый ввод
Одна строка → транзакция. Примеры:
- `кофе 1200` → расход 1 200 ₸, категория подбирается по слову (правила + история).
- `+350000 зарплата` → приход.
- `такси 2500 вчера #работа` → расход, дата вчера, тег «работа».
- `молоко 2x650 магнум` → позиция продукта «молоко», 2 × 650 ₸, магазин «Магнум».

Распознавание (счёт не указывается — деньги общие): знак `+` = приход; числа с `x`/`*`/`×` = количество × цена; слова `сегодня/вчера/позавчера` и даты `12.10`; `#тег`; известный магазин; остаток текста — описание, по нему ищется категория (ключевые слова категорий → последние совпадения в истории → «Прочее»).

### 5.4 Шаблоны
Частые операции («Обед 2500», «Проезд 200») сохраняются как шаблоны и создаются в один тап.

## 6. Копилки

- Название, иконка, цвет, целевая сумма, дедлайн (необязательно), автоотчисление % от прихода.
- **Пополнение** перекладывает деньги из свободных в копилку, **снятие** — обратно.
- **Депозит** — тоже копилка; проценты записываются приходом и, если капитализируются, пополнением копилки.
- Карточка копилки показывает:
  - прогресс-бар и процент;
  - сколько осталось;
  - если есть дедлайн: «откладывай N ₸ в день / неделю / месяц, чтобы успеть»;
  - **прогноз** по фактическому темпу пополнений за последние 90 дней: «при текущем темпе цель будет достигнута ~14 марта» или «темпа нет»;
  - историю пополнений и снятий, график накопления.
- Достигнутая цель помечается 🎉 и может быть закрыта (архив).

## 7. Категории и теги

- Категории расходов и доходов с иконкой (эмодзи) и цветом, есть стартовый набор.
- У категории есть **ключевые слова** для быстрого ввода (например, «Кафе»: кофе, латте, обед).
- Категории можно создавать, переименовывать, архивировать.
- **Теги** — свободные метки поверх категорий («отпуск», «др мамы»), по ним работает фильтр и отчёт.

## 8. Продукты и магазины

- Справочник продуктов: название, единица, категория по умолчанию.
- Справочник магазинов.
- Страница продукта:
  - **история цен** (цена за единицу во времени) — график;
  - **личная инфляция**: изменение цены относительно первой покупки и покупки полгода назад;
  - минимальная / средняя / последняя цена;
  - **где дешевле**: средняя и минимальная цена по магазинам;
  - сколько всего потрачено и куплено.
- Список продуктов сортируется по тратам, частоте, росту цены.

## 9. Бюджеты

- Лимит на категорию на месяц (или неделю).
- Прогресс-бар: зелёный до 80%, жёлтый 80–100%, красный > 100%.
- При сохранении расхода, после которого категория пересекла 80% или 100%, показывается предупреждение.
- Прогноз к концу периода по текущему темпу.

## 10. Регулярные платежи

- Название, приход/расход, сумма, категория, периодичность (каждый день / неделю / месяц / год, с интервалом), дата следующего платежа.
- Режим **авто**: при открытии приложения все просроченные платежи создаются автоматически.
- Режим **напоминание**: на главной появляется карточка «Пора оплатить: Интернет 7 990 ₸» с кнопками «Записать» / «Пропустить».

## 11. Отчёты

Период: **день / неделя / месяц / год / произвольный**, с навигацией ← →.

- Итоги: приход, расход, разница, средний расход в день.
- **Сравнение с прошлым периодом** (± ₸ и %).
- Структура расходов и доходов по категориям: ранжированные полосы с суммой и долей, хвост свёрнут в «Остальное».
- Динамика: столбики расходов/приходов по дням (для недели/месяца) или по месяцам (для года).
- **Календарь-тепловая карта** трат за месяц.
- Топ продуктов и топ магазинов за период.
- Отчёт по тегам.
- Клик по категории → список операций с этим фильтром.

## 12. Подсказки (инсайты)

Автоматически вычисляемые наблюдения на главной и в отчётах, например:
- «На Кафе в этом месяце ушло на 40% больше, чем в прошлом»;
- «Молоко подорожало на 18% за полгода»;
- «Бюджет на Продукты закончится примерно 24-го»;
- «Ты откладываешь в среднем 12% дохода»;
- «Самый дорогой день недели — пятница».

## 13. Операции

- Лента операций, сгруппированная по дням с итогом за день.
- Фильтры: период, тип (расходы, приходы, копилки, корректировки), категория, тег, поиск по заметке/продукту/магазину и по сумме.
- Редактирование и удаление (с отменой через тост).

## 14. Данные и настройки

- Экспорт всего в JSON (резервная копия) и импорт обратно.
- Экспорт операций в CSV (для Excel).
- Тема: светлая / тёмная / системная.
- Демо-данные: кнопка «Заполнить примером», чтобы посмотреть приложение в деле.
- Полный сброс данных (с подтверждением).

## 15. PWA и UX

- Сначала мобильная вёрстка: нижняя навигация, большая кнопка «+».
- На десктопе: боковая навигация.
- Устанавливается на телефон, работает офлайн.
